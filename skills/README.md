# Agent Skills Module (Milestone 3)

This directory is scaffolded for **Milestone 3: Agentic Routing & Specialized Skills**.

## Planned Skills

1. **`grounded_qa.md`**: Direct evidence-based answering of product and growth questions strictly grounded in Lenny's transcripts with source citations.
2. **`growth_action_plan.md`**: Generates prioritized execution roadmaps (problem statement, hypotheses, actions, ICE prioritization, validation experiments).
3. **`ship30_essay.md`**: Dedicated content skill encoding Ship 30 for 30 writing principles (~1,250 words, hook, narrative progression, skimmable formatting, actionable takeaways).
4. **`artifact_generation.md`**: Produces self-contained Markdown and sandboxed HTML/CSS artifacts for native rendering in the in-app Artifact Viewer.
